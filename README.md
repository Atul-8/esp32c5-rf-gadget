# ESP32-C5 RF Gadget

**English** | [简体中文](README.zh-CN.md)

A desktop RF survey gadget built on the **Seeed XIAO ESP32-C5** board
with the **Seeed Round Display for XIAO** (1.28" GC9A01 round LCD).
The board sweeps the 2.4 GHz / 5 GHz WiFi bands and renders the result
on the round display — completely on its own. A Python desktop app
(optional) taps the same serial stream for tables, heatmaps and CSV
exports; close the app and the gadget keeps sweeping.

Derived from the upstream **[ESPARGOS/esp-sdr](https://github.com/ESPARGOS/esp-sdr)**
project — this repository would not exist without it. See
[Acknowledgements](#acknowledgements) and the required
[notice of modifications](#notice-of-modifications-gpl-30) below.

## Features

**On the board** (ESP32-C5 + GC9A01 round display):

- **Offline autonomy** — boots straight into its own sweep + carousel;
  the PC app is an optional observer/configurator. Unplug it and the
  round display keeps going; if a host exits after stopping the sweep,
  the board resumes on its own after ~3 s of host silence.
- Device-side automatic sweep of 2.4 GHz and 5 GHz (30 windows per pass,
  ~3 s a lap), streamed over USB Serial/JTAG at 2 Mbaud as burst
  frames (~16 KB each).
- Round-display UI with three pages, switchable by touch or auto-paging
  carousel (per-page dwell seconds, default 8/25/8, remotely controllable):
  - **RING** — band color ring with per-band occupancy (time duty cycle).
  - **CHART** — channel power table with paging gestures.
  - **WATERFALL** — spectrum + time waterfall pinned to one channel.
- Touch gestures: vertical slide pages/pins channels; left strip and bottom
  dots switch views.
- Serial command set (`RD` prefix) for the PC: view/page control, gain,
  carousel dwell (`RD VIEWSEC`), diagnostics.

**On the PC** (`examples/esp32c5-rf-monitor/`):

- Desktop GUI (PySide6 + WebEngine, Chinese/English) with five pages:
  1. Live spectrum of the current window.
  2. Heatmap memory (band-sweep time-frequency).
  3. Rogue-AP hotspots (channel load + unknown devices).
  4. Channel occupancy — 38-channel duty cycle with CSV export.
  5. Round-display carousel control (start/stop/read back from the board).
- Gain control: manual index, host-side auto loop, or hardware AGC.
- A mock firmware (`--mock`) so everything can be tried without hardware,
  plus self-test probes (`--selftest`) and 130+ unit tests.
- CLI modes: `python -m app.live` (WiFi channel health check),
  `python -m app.waterfall`; further analysis modes (BLE-ad risk,
  5.8 GHz guard, capture) live under `modes/_legacy/`.

## Requirements

**Firmware** — build it on any machine that runs **ESP-IDF v6.1**
(Linux recommended; the Windows shell is usable but slow):

- Hardware: Seeed **XIAO ESP32-C5** dev board + Seeed **Round Display
  for XIAO** (GC9A01 round LCD, CHSC6X touch).
- ESP-IDF v6.1 with the ESP32-C5 target support installed.
- The `components/esp-dsp` submodule (see clone step below).
- A USB cable to the board (USB Serial/JTAG appears as a COM/tty port).

**PC application** — Python **3.10+** on Windows/Linux/macOS:

- `PySide6>=6.5` (Qt WebEngine shell), `numpy`, `pyserial>=3.5`
  (serial only; `--mock` and unit tests run on the standard library alone).

## Getting started

```sh
# 1. Clone with the DSP submodule
git clone https://github.com/Atul-8/esp32c5-rf-gadget.git
cd esp32c5-rf-gadget
git submodule update --init --recursive

# 2. Build the firmware (inside an ESP-IDF v6.1 environment)
idf.py set-target esp32c5
idf.py build
idf.py -p <PORT> flash monitor        # e.g. COM56 on Windows, /dev/ttyUSB0 on Linux
```

> Where to build: any host with ESP-IDF works. Windows-local builds are
> noticeably slower than Linux; a full rebuild must re-run `set-target`
> (ESP-IDF defaults to a different target on a clean build).

```sh
# 3. Run the desktop application
cd examples/esp32c5-rf-monitor
pip install -r host/requirements.txt

python host/app.py --port COM56 --gain-mode MANUAL --gain-index 60
python host/app.py --mock --scenario wifi_busy     # no hardware needed
# Windows: double-click host/start.bat instead.

# CLI (no GUI): WiFi channel health check over 60 s at fixed gain
python -m app.live --port COM56 --duration 60 --gain-index 60
python -m app.live --mock --duration 5             # mock firmware

# 4. Tests & self-check
cd examples/esp32c5-rf-monitor/host
python -m unittest discover -s tests -t tests      # host unit tests
python app.py --selftest --mock --seconds 5        # end-to-end self-test
```

Open the GUI, pick the port, press **Start**; use the top navigation to move
between the five pages and the language switcher for 中/en.
